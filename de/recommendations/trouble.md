    list:
      - name: 'Zustand einschätzen'
        description: 'Futterverweigerung, Lethargie, Erbrechen, Durchfall oder hohes Fieber sind Gründe, sofort einen Tierarzt zu kontaktieren. Betreiben Sie keine Selbstmedikation.'
      - name: 'Klinik kontaktieren'
        description: 'Rufen Sie die nächstgelegene 24-Stunden-Klinik an. Beschreiben Sie die Symptome, damit der Arzt Ihnen sagen kann, ob eine dringende stationäre Aufnahme erforderlich ist oder ob Sie einen regulären Termin vereinbaren können.'
      - name: 'Für Ruhe sorgen'
        description: 'Isolieren Sie das Haustier von Kindern und anderen Tieren. Stellen Sie einen Napf mit Wasser in die Nähe. Geben Sie keine Medikamente ohne ärztliche Verordnung.'

    title: '... Wenn das Haustier wegläuft'
    list:
      - name: 'In der Nähe des Hauses suchen'
        description: 'Hunde laufen normalerweise nicht weit weg. Durchsuchen Sie den Hof, die Hauseingänge und den nächsten Park. Katzen verstecken sich im Umkreis von 100 Metern – schauen Sie unter Autos und in Kellern nach.'
      - name: 'Flyer aufhängen'
        description: 'Geben Sie den Namen des Tieres, besondere Merkmale, den Stadtteil und Ihre Telefonnummer an. Bieten Sie eine Belohnung an. Veröffentlichen Sie einen Beitrag in lokalen Chats und sozialen Netzwerken.'
      - name: 'Tierheime überprüfen'
        description: 'Rufen Sie nahegelegene Tierheime und die Tierkontrolle an. Senden Sie ihnen ein aktuelles Foto des Tieres und eine Beschreibung der Merkmale.'
  - type: 'steps'
    title: '... Wenn das Haustier verstorben ist'
    list:
      - name: 'Sich Zeit geben'
        description: 'Trauer ist normal. Schämen Sie sich nicht für Ihre Gefühle. Der Verlust eines Freundes ist ein großer Verlust, und jeder braucht Zeit, um damit umzugehen.'
      - name: 'Abschied organisieren'
        description: 'Sie können sich an eine Tierklinik für die Einäscherung wenden oder einen Ort für die Beerdigung wählen (unter Berücksichtigung der Hygienevorschriften). Erlauben Sie sich, in Würde Abschied zu nehmen.'
      - name: 'Auf sich selbst achten'
        description: 'Bleiben Sie mit Ihrer Trauer nicht allein. Sprechen Sie mit Angehörigen, wenden Sie sich an einen Psychologen oder an Selbsthilfegruppen für Tierhalter.'
